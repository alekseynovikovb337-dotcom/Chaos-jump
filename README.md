# Chaos Jump

Standalone Geode mod project targeting Geometry Dash 2.2081 (Android/desktop).

## Planned features
- Chaos Jump: randomized jump force
- Jump Force and Random Jump editor triggers
- Super Jump and Gravity Chaos triggers
- Chaos Reset and Jump Effect triggers
- In-level settings for intensity, force range, and super-jump chance

## Build
Build using the Geode SDK and toolchain for the target Geometry Dash version.

## Status
Initial project scaffold and randomized force logic are committed. Gameplay hook,
custom editor trigger registration/serialization, trigger execution, settings UI,
and Android package still require implementation and SDK build/testing. This is not
an installable release yet.
